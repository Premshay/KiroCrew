# Arc cooperation repairs

Keep useful arc context in each bounded turn prefix. Close implementation claims
from explicitly linked merge receipts. Let the owner or coordinator resolve a
stale claim as themselves, with a reason.

- Preserve verification, open-work summaries and fresh entries before long lists.
- Keep cursors on the last fully delivered entry; share space between arcs.
- Merge only closes linked implementation work, never review or milestone acceptance.
- Closure keeps the original claim and the closing author's identity.
- Keep owner-only setup, existing storage, sync and caller authentication.

Builds on the approved 2026-10-31 arc coordination design and pilot evaluation.
No live claim changes or gateway restart are part of implementation verification.
